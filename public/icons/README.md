# ShiftPilot Icons

Place the following icon files in this directory before deploying:

| File | Size | Usage |
|------|------|-------|
| `icon-192.png` | 192x192 | PWA icon (Android, manifest) |
| `icon-512.png` | 512x512 | PWA icon (splash, store) |
| `apple-touch-icon.png` | 180x180 | iOS home screen |
| `favicon.ico` | 32x32 | Browser tab |

## Design direction
- Background: `#0b0d10` (app background color)
- Accent: `#2dd4bf` (teal accent)
- Shape: Rounded square, minimal — a compass or steering wheel icon works well
- No Amazon orange, no Uber black-white, no DoorDash red — original identity only

## Generating icons
You can use https://realfavicongenerator.net or Figma to export all sizes from a single SVG.
